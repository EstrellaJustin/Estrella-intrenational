# 伊斯特拉国际 · Istra International

> 高端国际身份规划平台 · 全球出国项目智能数据库

网站打开后直接进入「全球出国项目大全」：十大一级分类以 **三列矩阵** 展示（PC 3 列 / 平板 2 列 / 手机 1 列）。
每个分类卡片含：分类图标 + 一级分类名称 + 二级分类链接 + 项目数。
点击一级分类 → 分类页；点击二级分类 → 项目列表页；点击项目 → 详情页。
首页唯一任务：让用户找到全球出国项目（无营销模块 / 无热门推荐 / 无 AI 入口按钮）。

## 全球旅游探索 · 全球城市探索系统

- 用户路径：旅游探索 → 选择国家 → 查看热门城市（5–10 城）→ 城市详情（介绍/景点/玩法攻略/旅行建议）→ 签证推荐
- 页面：`travel.html`（区域分类）→ `travel-country.html?id=xx`（国家）→ `travel-city.html?id=xx`（城市）
- 数据库：`src/data/travel.json`（21 国概览）+ `src/data/cities.json`（**30 国 / 215 城**）
- 国家详情：① 国家概览（简介/地理位置/气候/最佳时间/文化特色/货币/语言）② 热门城市（5–10 城，独立城市入口）③ 旅行信息 ④ 特色体验 ⑤ 长期发展关联
- 城市详情七大模块：① 城市介绍（定位/人口/经济地位/特色/适合人群）② 城市风景（景点图片/介绍/推荐游玩时间）③ 游玩攻略（一日/三日/五日/深度路线）④ 旅行预算（经济/普通/高品质：住宿/交通/餐饮/门票）⑤ 适合旅行季节（春夏秋冬）⑥ 签证推荐（类型/适合/申请条件/周期/停留）⑦ 如果你喜欢这里（留学/工作/长期居留自然关联）
- 视觉：深蓝高级 + 国际旅行杂志风；城市/景点大图（本地 `assets/travel/`，离线可用）
- 图片绑定（第一阶段）：`src/data/travel-images.json` 独立管理三级图片（country/city/attraction），每个国家/城市/景点均有独立 `image` 字段，页面按 ID 精准读取，禁止随机图/共用图/无关风景图；已验证日本→东京→东京塔、巴黎→埃菲尔铁塔、纽约→时代广场等链路
- 图片资源修复：路径统一为 `assets/images/travel/{country,city,attractions}/`（890 张全部本地存在）；全局 `onerror` 回退到默认占位图（禁止空白）；`loading="lazy"` 懒加载；随机 20 国 × 3 城 × 3 景点抽样 240/240 成功
- 未来扩展预留：旅游路线推荐 / AI 旅行规划 / 机票酒店接口 / 私人定制旅行
- 生成器：`scripts/generate-cities.js`（`node scripts/generate-cities.js` 重新生成）

## AI 评估结果页（20 个个性化匹配方案）

- 取消“国家列表 + 项目列表”分离展示，改为「20 个个性化匹配方案」：每个方案 = 国家 + 项目 + 签证类型 + 匹配指数 + 适合原因 + 申请条件（学历/语言/职业/资金/经验）+ 预计成本 + 预计周期 + 优势/限制 + 查看详情
- 排序：按匹配度/目标/资金/职业/年龄/学历/语言/风险偏好综合评分（TOP 1–20）
- 分组：高匹配 TOP 5 / 推荐考虑 6–15 / 备用方案 16–20
- 顶部「为什么推荐这些方案」：基于你的年龄/职业/可接受投入/语言，直接给出前三项目
- 保留：不推荐方向 + 未来路线规划；评估逻辑不变，仅结果展示重构

## AI 匹配评分系统（v2 · 8 维度加权）

- 评分维度与权重：年龄 15% / 学历 15% / 职业 20% / 工作经验 15% / 语言 10% / 资金 10% / 家庭 5% / 出国目标 10%
- 每个项目按用户数据逐维计算，再按推荐集归一化为 55–95 匹配度（最高不超过 95%）
- 自然分布区间：优秀 85–95 / 良好 70–85 / 一般 55–70 / 不推荐 <55
- 结果卡片新增：**推荐理由 / 用户优势 / 不足条件 / 下一步建议**（+ 原有申请条件 / 成本 / 周期 / 优劣）
- 评估结果与推荐分数继续保存到用户数据库

## AI 评估系统（v9 · 全面重构）

- 定位：全球人生规划评估（适用于学生、普通工人、技术人员、白领、创业者、企业家、退休人士）
- 7 步信息采集 + 进度百分比（0% / 35% / 70% / 100%）：
  1 基本信息（年龄/性别可选/所在地区/婚姻/子女/家庭）
  2 职业能力（14 大类 × 二级职业数据库，如制造业→机械操作/焊工/电工/汽车维修；技能描述/年限/证书/学习意愿）
  3 教育语言（学历/专业/毕业年份/学历证明/英语/其他语言/语言考试/学习当地语言意愿）
  4 财务情况（7 档可投入资金/资金来源/低成本/边工作边发展/先学习后就业）
  5 家庭生活（父母团聚/子女教育 + 健康信息自愿填写，仅用于匹配医疗资源，不构成淘汰条件）
  6 出国目标（10 项多选 + 前三排序）
  7 个性偏好（居住环境/气候/节奏/风险路线/偏远地区·语言·职业转换接受度）
- 结果：20 个个性化匹配方案（TOP5 / 6–15 / 16–20）+ 为什么推荐（年龄/职业/技能/资金/语言）+ 不推荐方向 + 3 阶段路线
- 匹配引擎：目标/14 大类职业+二级职业/年龄/学历/语言/资金/家庭/健康(非淘汰)/居住/气候/风险/接受度 多维度综合评分

## AI 全球人生路径规划评估中心（12 阶段）

- 定位：不是移民资格测试，而是「全球人生路径规划 AI 系统」——先理解用户，再匹配项目
- 覆盖全人群：学生 / 应届 / 职场人士 / 技术人才 / 创业者 / 企业家 / 家庭用户 / 高净值人士 / 退休人士
- 流程（智能对话式，选择为主、填写为辅）：个人基本画像 → 出国核心动机（多选+前三排序）→ 职业与能力画像 → 教育背景 → 语言能力 → 经济与资源 → 家庭因素 → 生活方式偏好（气候/城市/节奏）→ 文化适应能力（1-10 分）→ 风险偏好 → 国家偏好 → 未来愿景（开放描述）
- 进度：Step 01/12 + 蓝色进度条 + 12 段进度点 + Q01–Q12 对话式标签
- 报告《全球人生路径规划报告》：① 用户全球画像 ② 国家匹配度（前 5 名+百分比+原因）③ 项目匹配（方向标签，可打开详情）④ 不推荐方向（附原因）⑤ 未来路线规划（半年准备 / 1-2 年申请 / 3-5 年达成）
- 匹配引擎：身份 / 年龄 / 职业 / 学历 / 收入资金 / 家庭 / 动机 / 气候 / 文化适应 / 风险偏好 / 目标国家 多维度评分
- UI：深蓝私人银行风，深色透明输入框 + 白底深蓝字按钮
